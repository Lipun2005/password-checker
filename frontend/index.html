K-anonymity

How the check stays private

The Have I Been Pwned Pwned Passwords range API answers with every hash that shares a short prefix. Your browser decides whether the rest of your hash is in that list.

01

Hash on this page

The password is encoded as UTF-8 and hashed with SHA-1 in the browser. The server that hosts this app never receives the password.

02

Ask for a range

Only the first 5 characters of the hash go to the local server. It requests https://api.pwnedpasswords.com/range/ plus that prefix.

03

Compare the suffix here

The response is a list of hash endings and how often each was seen. The remaining 35 characters are matched in the browser. A missing suffix is a no-match result.

Read this with every clear result

No breach match does not guarantee safety.

A clear result means the password was not found in the Have I Been Pwned password corpus checked by this app. It can still be guessed, reused, taken from a device, or exposed somewhere this dataset does not include.

  • Use a different long password for each account.
  • Prefer a password manager when you do not need to memorize the password.
  • If a password has a breach match, stop using it.
  • This app does not store passwords, hashes, or personal information.

BreachGuard Café runs on this computer. Breach data comes from Have I Been Pwned, an independent service by Troy Hunt.
